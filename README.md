# Flexbox Sandbox
Ce projet est un simple _Sandbox_ permettant de pratiquer les propriétés principales de Flexbox sur les containers parents et la manière dont ça influe les éléments enfants.

Pour utiliser le projet, vous devez :

1. Cloner le projet
```bash
git clone https://github.com/ThomasTirole/flexbox.git
```

2. Ouvrir le projet dans WebStorm ou un éditeur de code de votre choix
3. Ouvrir le fichier `index.html`
4. Lancer la preview du projet dans votre navigateur à l'aide de WebStorm ou en ouvrant le fichier `index.html` directement dans votre navigateur
